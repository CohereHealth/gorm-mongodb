GORM for MongoDB supports both session-based transactions (legacy) and native MongoDB transactions (MongoDB 4.0+).

== Session-Based Transactions (Legacy)

GORM batches inserts and updates until the session is flushed, providing transaction-like semantics:

[source,groovy]
----
static transactional = 'mongo'
----

[source,groovy]
----
Person.withTransaction { status ->
    new Person(name:"Bob", age:50).save()
    throw new RuntimeException("bad")
    new Person(name:"Fred", age:45).save()
}
----

== Native MongoDB Transactions

For true ACID guarantees, use native MongoDB transactions (requires MongoDB 4.0+):

=== Global Configuration

[source,yaml]
----
grails:
  mongodb:
    nativeTransactions: true
----

=== Selective Usage

[source,groovy]
----
Person.withNativeTransaction { session ->
    new Person(name:"Bob", age:50).save()
    new Address(person: person, street: "123 Main St").save()
    // True ACID transaction across multiple collections
}
----

=== Spring Integration

[source,groovy]
----
@Service
class PersonService {
    @Transactional
    Person createPerson(String name) {
        // Uses native transactions when enabled
        return new Person(name: name).save()
    }
}
----

See link:native-transactions.html[Native Transactions] for complete documentation.
